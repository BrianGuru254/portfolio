# Brian Kiprop — Portfolio

A single-page portfolio for Brian Kiprop, built with React Router, React,
TypeScript, Tailwind CSS, and the AeroShards WebGPU background.

## Run locally

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run typecheck
npm run build
```

## Featured work

The Mitombili SDA Church Website is linked to its public source repository and
the demo URL listed in that repository's README. Its frontend uses React,
TypeScript, and Tailwind CSS. The repository also contains an Express API with
sermon and event routes.

The Waste Management System and E-Commerce Platform were not present in the
public repository list inspected for this portfolio, so they are not shown as
verified projects.

## Notes

The contact section links to Brian's public GitHub and LinkedIn profiles. It
does not claim to accept or send email messages. The decorative AeroShards
animation requires browser WebGPU support; if WebGPU is unavailable, the rest
of the portfolio remains usable and an error notice is shown.
